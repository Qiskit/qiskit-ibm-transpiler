The Qiskit Function ``ibm/transpiler-function`` is deprecated and no longer available. :class:`~qiskit_ibm_transpiler.transpiler_service.TranspilerService`
now raises a ``ValueError`` with a deprecation message when it is created, for every value of ``ai``. Before this change, the cloud returned
a ``404`` error ("Qiskit Function ibm/transpiler-function doesn't exist") for ``ai="false"`` and ``ai="auto"``, and only ``ai="true"`` raised a clear error.
Use the AI transpiler passes in local mode instead.
